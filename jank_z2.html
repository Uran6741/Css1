Definicja CSS - Kaskadowych Arkuszy Styli

CSS - Kaskadowe Arkusze Stylów (z ang. Cascading Style Sheets) jest to specjalny język stworzony w celu elastycznego zarządzania sposobem formatowania (wyglądem) elementów znajdujących się na stronach WWW.

Wytłumaczenie skrótu CSS (po angielsku):

  • C – Cascading – oznacza kaskadowość, czyli hierarchię stosowania stylów
  • S – Style – oznacza style, czyli reguły formatowania elementów
  • S – Sheets – oznacza arkusze, czyli pliki lub bloki zawierające reguły CSS
