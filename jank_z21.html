Co znaczy skrót ID? ID pochodzi od angielskiego słowa "Identifier" i oznacza identyfikator. Jest to unikalny atrybut używany do jednoznacznego oznaczenia elementu w dokumencie HTML.
Jaki jest cel stosowania ID? Celem stosowania ID jest możliwość odwołania się do konkretnego, unikalnego elementu w dokumencie za pomocą CSS lub JavaScript. Pozwala to na precyzyjne formatowanie wybranego elementu.
Jakie jest znaczenie znaku #? Znak # (hash) w CSS służy do oznaczenia selektora ID. Jest używany przed nazwą identyfikatora, aby wskazać, że odnosimy się do elementu z określonym atrybutem id.
Jak następuje wywołanie ID (wraz z wytłumaczeniem)? Wywołanie ID następuje przez użycie znaku # przed nazwą identyfikatora w arkuszu stylów CSS, np. #mojeID { color: red; }. W HTML element otrzymuje atrybut id="mojeID". Selektor #mojeID odnosi się do tego konkretnego elementu.
Uwagi na temat stosowania ID (trzy konieczne wyliczenia)
  1. ID musi być unikalne w całym dokumencie HTML - nie może być dwóch elementów z tym samym identyfikatorem.
  2. Nazwa ID powinna zaczynać się od litery (nie od cyfry lub znaku specjalnego).
  3. ID jest wrażliwe na wielkość liter - "MojeID" i "mojeid" są różnymi identyfikatorami.
