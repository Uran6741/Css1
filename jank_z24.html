1. 1. Jakie standardowo dostępne są czcionki w systemie Windows?

    W systemie Windows standardowo dostępne powinny być czcionki:
    • Times New Roman (szeryfowa)
    • Arial (bezszeryfowa)
    • Courier New (monotypiczna)

  2. 2. Jakich czcionek dodatkowo dostarcza Internet Explorer?

    Dodatkowo z Internet Explorerem dostarczane są:
    • Verdana
    • Tahoma
    • Trebuchet MS
    • Georgia

  3. 3. Wymień rodziny ogólne czcionek (pięć)

    Rodziny ogólne czcionek:
    • serif – czcionka szeryfowa (końcówki znaków posiadają „ozdobniki"). Przykłady: Times New Roman, Georgia, Garamond, Bodoni.
    • sans-serif – czcionka bezszeryfowa (końcówki znaków są proste). Przykłady: Arial, Verdana, Trebuchet MS, Helvetica.
    • monospace – czcionka o stałej szerokości znaków – monotypiczna (wygląda jak pisana na maszynie). Przykłady: Courier, Courier New.
    • cursive – czcionka mająca pewne cechy pochyłej (wygląda jak pisana ręcznie).
    • fantasy – czcionka fantazyjna (dekoracyjna).

  4. 4. Kiedy i jak stosujemy rodziny czcionek?

    Rodziny ogólne wykorzystuje się jako ostatnią alternatywę – jeśli użytkownik nie będzie posiadał żadnej czcionki, której nazwę wpisaliśmy wprost. Dlatego zwykle rodzinę ogólną podaje się na samym końcu listy nazw czcionek.

    Sposób deklaracji:
    body { font-family: Arial, Helvetica, Verdana, sans-serif; }

    Dzięki temu nawet jeśli użytkownik nie posiada żadnej z podanych czcionek, strona zostanie wyświetlona przy użyciu czcionki podobnej do zdefiniowanych.

  5. 5. Rodzaje wyrównania tekstu

    Wyrównanie tekstu (właściwość CSS: text-align) może być:
    1. left – wyrównanie do lewego marginesu (domyślnie)
    2. right – wyrównanie do prawego marginesu
    3. center – wyśrodkowanie
    4. justify – wyrównanie do obu marginesów jednocześnie (justowanie)
    Składnia: selektor { text-align: wartość; }

  6. 6. Kolor tekstu

    Właściwość CSS odpowiedzialna za kolor tekstu to color.

    Składnia: selektor { color: kolor; }

    Właściwość color odnosi się do wszystkich elementów HTML. Jako kolor podajemy definicję koloru w jednym z obsługiwanych formatów:
    • Nazwa koloru: color: red;
    • Zapis heksadecymalny: color: #FF0000;
    • Zapis RGB: color: rgb(255, 0, 0);

  7. 7. Dekoracja tekstu

    Tekst można „udekorować" w następujący sposób:

    Składnia: selektor { text-decoration: dekoracja; }

    Wartości właściwości text-decoration:
    1. Podkreślenie – text-decoration: underline;
    2. Przekreślenie – text-decoration: line-through;
    3. Nadkreślenie – text-decoration: overline;
    4. Migotanie tekstu (tylko Netscape/Mozilla/Opera) – text-decoration: blink;
    5. Bez dekoracji – text-decoration: none;

  8. 8. Warianty czcionek

    Wariant czcionki kontrolowany jest właściwością font-variant.

    Składnia: selektor { font-variant: wartość; }

    Możliwe wartości:
    • normal – czcionka normalna (podstawowa)
    • small-caps – kapitaliki (tekst napisany wielkimi literami, lecz czcionką o wielkości małych liter)
    Przykład: p { font-variant: small-caps; }

  9. 9. Pogrubienie czcionek

    Grubość czcionki kontrolowana jest właściwością font-weight.

    Składnia: selektor { font-weight: wartość; }

    Możliwe wartości:
    • normal – czcionka normalna (podstawowa)
    • bold – czcionka pogrubiona
    • bolder – grubsza od bieżącej
    • lighter – cieńsza od bieżącej
    • Wartości liczbowe: 100, 200, 300, 400 (odpowiednik normal), 500, 600, 700 (odpowiednik bold), 800, 900 – każdy następny numer wskazuje wagę czcionki przynajmniej tak samo wytłuszczonej jak poprzednia.
    Uwaga: Niektóre rodziny czcionek mogą nie posiadać wszystkich dziewięciu stopni wytłuszczenia.

  10. 10. Rozmiar czcionek

    Rozmiar czcionki kontrolowany jest właściwością font-size.

    Składnia: selektor { font-size: rozmiar; }

    Możliwe wartości (słowa kluczowe):
    • xx-small – najmniejsza
    • x-small – mniejsza
    • small – mała
    • medium – średnia
    • large – duża
    • x-large – większa
    • xx-large – największa
    • larger – większa od bieżącej
    • smaller – mniejsza od bieżącej
    Możliwe jednostki miar:
    • Piksele: font-size: 15px;
    • Punkty: font-size: 10pt;
    • Centymetry: font-size: 0.5cm;
    • Cale: font-size: 0.25in;
    • Pica: font-size: 1pc;
    • Em: font-size: 1em;
    • Ex: font-size: 2ex;

  11. 11. Transformacja tekstu

    Składnia: selektor { text-transform: transformacja; }

    Właściwość odnosi się do wszystkich elementów. Możliwe wartości:
    • none – bez zmian (domyślnie)
    • capitalize – zamiana pierwszych liter wszystkich wyrazów na wielkie
    • uppercase – zamiana wszystkich liter na wielkie
    • lowercase – zamiana wszystkich liter na małe
    Przykład: p { text-transform: uppercase; }

  12. 12. Wcięcia tekstu

    Składnia: selektor { text-indent: wcięcie; }

    Właściwość odnosi się do elementów blokowych. Wcięcie należy podać używając jednostek miary:
    • Piksele – px
    • Punkty edytorskie – pt
    • Wysokość litery "x" – ex
    • Wysokość aktualnej czcionki – em
    • Centymetry lub milimetry – cm, mm
    • Cale – in (1in = 2.54cm)
    • Procent wielkości nadrzędnej – %
    Przykład: p { text-indent: 2cm; }

  13. 13. Odstęp między wierszami

    Składnia: selektor { line-height: odstęp; }

    Właściwość odnosi się do wszystkich elementów. Odstęp podajemy używając jednostek miar (px, pt, ex, em, cm, mm, in, %) lub wartości normal, która przywraca wartość domyślną.

    Przykład: p { line-height: 1.5cm; }

  14. 14. Odstęp między wyrazami

    Składnia: selektor { word-spacing: odstęp; }

    Właściwość odnosi się do wszystkich elementów. Odstęp podajemy używając jednostek miar (px, pt, ex, em, cm, mm, in) lub wartości normal, która przywraca wartość domyślną.

    Przykład: p { word-spacing: 10px; }

  15. 15. Odstęp między literami

    Składnia: selektor { letter-spacing: odstęp; }

    Właściwość odnosi się do wszystkich elementów. Odstęp podajemy używając jednostek miar (px, pt, ex, em, cm, mm, in) lub wartości normal, która przywraca wartość domyślną.

    Przykład: p { letter-spacing: 5px; }

  16. 16. Łączenie właściwości czcionek i tekstu

    Właściwość skrótowa font pozwala zebrać wszystkie atrybuty dotyczące czcionek w jednym miejscu.

    Składnia: selektor { font: wartości atrybutów; }

    Prawidłowa kolejność wartości atrybutów:
    1. font-style
    2. font-variant
    3. font-weight
    4. font-size (po tym ukośnik „/"; bezpośrednio przed line-height)
    5. line-height
    6. font-family
    Przykład łączonej reguły:
    p { font: italic small-caps bold 14px/1cm Arial, Helvetica, Verdana, sans-serif; }

    Można pominąć niektóre wartości – te, które nie są określone, przyjmują wartości domyślne.
