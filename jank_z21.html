Zadanie 21 – Identyfikatory ID w CSS

Pojęcie Znaczenie pojęcia
Co znaczy skrót ID? ID pochodzi od angielskiego słowa identifier, co oznacza identyfikator. Jest to unikalny atrybut HTML pozwalający jednoznacznie zidentyfikować dany element na stronie.
Jaki jest cel stosowania ID? Celem stosowania ID jest zróżnicowanie podobnych elementów na stronie. Dzięki identyfikatorowi możemy przypisać specyficzne formatowanie CSS do konkretnego, pojedynczego elementu, odróżniając go od pozostałych elementów tego samego typu.
Jakie jest znaczenie znaku # ? Znak # jest stosowany w CSS jako prefix przed nazwą identyfikatora. Oznacza on, że poniższa reguła dotyczy elementu o określonym atrybucie id. Przykład: #pochyly { font-style: italic; }
Jak następuje wywołanie ID (wraz z wytłumaczeniem)? Wywołanie identyfikatora składa się z dwóch kroków:

1) Definicja w CSS: Odpowiedni wpis składa się z selektora, do którego planujemy przypisać identyfikator, oraz z nazwy poprzedzonej znakiem #.
Przykład: p#pochyly { font-style: italic; font-size: 20pt; }

2) Użycie w HTML: W kodzie HTML do danego elementu dodajemy atrybut id z nazwą zdefiniowaną w CSS.
Przykład: <p id="pochyly">Tekst pochyły</p>
Uwagi na temat stosowania ID (trzy)
  1. Różnica między id a class: Identyfikator może wystąpić tylko raz w całym dokumencie, natomiast klasę można powielać do woli.
  2. Działanie błędu: Podobnie jak klasy, identyfikatorów możemy używać tyle razy, ile razy uznamy to za konieczne. Działanie takie jest błędem, ale nie wpływa na poprawność działania strony.
  3. Unikalność elementów: Elementy oznaczone ID muszą być unikatowe, tzn., że na jednej stronie może wystąpić tylko 1 element z takim ID. Jeśli nie mamy pewności, czy element wystąpi więcej niż raz, można bez obaw użyć atrybutu class, które może być przypisane do nieskończenie wielu elementów.
