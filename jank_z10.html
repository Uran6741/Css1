1. Wymienić oraz opisz dwie części selektora:

    Reguła CSS składa się z dwóch głównych części:

    • Selektor – wskazuje element (lub elementy) HTML, któremu mają być nadane style. Przykłady: p (wszystkie akapity), h1 (nagłówki h1), .klasa (elementy z daną klasą), #id (element z danym identyfikatorem).
    • Blok deklaracji – zawarty w nawiasach klamrowych { }, zawiera jedną lub więcej deklaracji (par właściwość: wartość), które określają sposób formatowania wskazanego elementu.
    selektor { właściwość: wartość; }

  2. Znaczenie nawiasów klamrowych {...}:

    Nawiasy klamrowe { } stanowią blok deklaracji w regule CSS. Zawierają wszystkie deklaracje (pary właściwość: wartość) przypisane do danego selektora.
    • Otwierający nawias { – otwiera blok deklaracji.
    • Zamykający nawias } – kończy blok deklaracji.
    Bez nawiasów klamrowych przeglądarka nie wie, które deklaracje należą do danego selektora i nie zastosuje stylów.

    p {
        color: red;
        font-size: 14px;
    }

  3. Opisz cechę:

    Cecha (właściwość, ang. property) to pierwsza część deklaracji CSS. Określa co chcemy zmienić w wyglądzie elementu. Cechę oddzielamy od wartości dwukropkiem (:).

    Przykłady cech:

    • color – kolor tekstu
    • font-size – rozmiar czcionki
    • background-color – kolor tła
    • font-family – krój czcionki
    • text-align – wyrównanie tekstu
    • border – obramowanie elementu

  4. Opisz wartości:

    Wartość (ang. value) to druga część deklaracji CSS. Określa jak ma wyglądać element – konkretna wartość przypisana do cechy. Wartość zapisujemy po dwukropku, a kończymy średnikiem (;).

    Przykłady wartości:

    • dla color: red, #FF0000, rgb(255,0,0)
    • dla font-size: 14px, 12pt, 1em, 16mm
    • dla font-family: Arial, "Times New Roman"
    • dla text-align: left, center, right, justify
    • dla background-color: yellow, #FFFF00

  5. Kiedy stosujemy znak średnika (;), kiedy nie jest konieczny:

    Średnik (;) stosujemy do oddzielania deklaracji od siebie wewnątrz bloku klamrowego.
    Po ostatniej deklaracji w bloku średnik nie jest konieczny, jednak zaleca się jego stosowanie – ułatwia późniejsze dodawanie nowych właściwości i zapobiega błędom.

    p {
        color: red;           ← średnik wymagany
        font-size: 14px;   ← średnik opcjonalny (ostatnia deklaracja)
    }
